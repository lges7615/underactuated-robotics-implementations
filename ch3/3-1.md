# 3.1 The Acrobot

## **概述**
Acrobot 是一種經典的 **欠驅動（Underactuated）機械系統**，其結構類似於雙擺（Double Pendulum），但僅在第二個關節（elbow）施加控制輸入，而第一個關節（shoulder）無法直接驅動。因此，Acrobot 需要透過動態運動來調控其姿態，這使其成為機器人控制與非線性動力學研究中的重要測試平台。

該系統在 **機器人學（Robotics）** 和 **最佳控制（Optimal Control）** 領域中具有廣泛應用，尤其在 **擺盪至直立（Swing-Up）控制** 和 **增強學習（Reinforcement Learning）** 相關研究中占據重要地位。

## **Acrobot 的動力學建模**

### **1️⃣ 狀態變數定義**
Acrobot 系統的狀態向量可定義為：
\[
q = \begin{bmatrix} \theta_1 \\ \theta_2 \end{bmatrix}, \quad
\dot{q} = \begin{bmatrix} \dot{\theta}_1 \\ \dot{\theta}_2 \end{bmatrix}
\]
其中：
- **\(\theta_1\)**：上連桿的角度（肩部關節），0 度對應於懸垂位置。
- **\(\theta_2\)**：下連桿相對於上連桿的角度，0 度表示兩者對齊。

### **2️⃣ 運動方程推導（拉格朗日動力學）**
應用 **拉格朗日方程（Lagrange's Equations）**，Acrobot 的運動方程可表述為：
\[
M(q) \ddot{q} + C(q, \dot{q}) \dot{q} + G(q) = B u
\]
其中：
- **\(M(q)\)**：質量矩陣（Mass Matrix），描述系統慣性。
- **\(C(q, \dot{q})\)**：科氏力與離心力矩陣（Coriolis and Centrifugal Forces）。
- **\(G(q)\)**：重力向量（Gravity Vector），對應於重力對各關節施加的力矩。
- **\(B\)**：控制輸入矩陣，決定作用於系統的控制力矩。
- **\(u\)**：外部控制輸入（僅施加在第二關節）。

#### **(1) 質量矩陣 M(q)**
\[
M(q) =
\begin{bmatrix}
I_1 + I_2 + m_2 l_1^2 + 2 m_2 l_1 l_{c2} \cos(\theta_2) & I_2 + m_2 l_1 l_{c2} \cos(\theta_2) \\
I_2 + m_2 l_1 l_{c2} \cos(\theta_2) & I_2
\end{bmatrix}
\]

#### **(2) 科氏力與離心力矩陣 C(q, \dot{q})**
\[
C(q, \dot{q}) =
\begin{bmatrix}
-2 m_2 l_1 l_{c2} \sin(\theta_2) \dot{\theta}_2 & -m_2 l_1 l_{c2} \sin(\theta_2) \dot{\theta}_2 \\
m_2 l_1 l_{c2} \sin(\theta_2) \dot{\theta}_1 & 0
\end{bmatrix}
\]

#### **(3) 重力向量 G(q)**
\[
G(q) = \begin{bmatrix} -m_1 g l_{c1} \sin(\theta_1) - m_2 g (l_1 \sin(\theta_1) + l_{c2} \sin(\theta_1 + \theta_2)) \\ - m_2 g l_{c2} \sin(\theta_1 + \theta_2) \end{bmatrix} \]

#### **(4) 控制輸入矩陣 B**
\[ B = \begin{bmatrix} 0 \\ 1 \end{bmatrix} \]

## **3️⃣ Python 實作 Acrobot 動力學**

```python
import numpy as np
from scipy.integrate import solve_ivp
import matplotlib.pyplot as plt

# 物理參數
g = 9.81
m1, m2 = 1.0, 1.0
l1, l2 = 1.0, 1.0
lc1, lc2 = l1/2, l2/2
I1, I2 = m1 * l1**2 / 3, m2 * l2**2 / 3

def acrobot_dynamics(t, state, u):
    theta1, theta2, theta1_dot, theta2_dot = state
    sin2, cos2 = np.sin(theta2), np.cos(theta2)

    M = np.array([
        [I1 + I2 + m2 * l1**2 + 2 * m2 * lc2 * l1 * cos2, I2 + m2 * lc2 * l1 * cos2],
        [I2 + m2 * lc2 * l1 * cos2, I2]
    ])

    C = np.array([
        [-m2 * lc2 * l1 * sin2 * theta2_dot**2],
        [m2 * lc2 * l1 * sin2 * theta1_dot**2]
    ])

    G = np.array([
        [-m1 * g * lc1 * np.sin(theta1) - m2 * g * (l1 * np.sin(theta1) + lc2 * np.sin(theta1 + theta2))],
        [-m2 * g * lc2 * np.sin(theta1 + theta2)]
    ])

    B = np.array([[0], [1]])
    tau = np.array([u])
    q_ddot = np.linalg.solve(M, G + B @ tau + C).flatten()

    return [theta1_dot, theta2_dot, q_ddot[0], q_ddot[1]]
```

## **4️⃣ 結論與未來研究方向**
- Acrobot 屬於 **欠驅動系統**，其控制難度較高，適用於研究非線性控制方法。
- 透過 **拉格朗日力學**，可獲得系統的數學模型並進行模擬。
